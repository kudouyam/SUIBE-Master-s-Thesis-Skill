# 校方规范来源 / School source documents

本 Skill 的主规则来自此前提供的两份上海对外经贸大学硕士论文资料：

1. 《上海对外经贸大学硕士学位论文内容和格式要求（2020 年修订）》，共 7 页；
2. 《上海对外经贸大学硕士学位论文格式范例》，共 8 页。

**出于公开再分发授权尚未核实的考虑，原始校方 PDF 暂不随公共仓库附带。**

能独立使用的规格对照表已经在 [references/01_学校规范逐项对照.md](../references/01_学校规范逐项对照.md)，并提供具体页码。任何情况下，**规范二次整理不构成学校官方文件**；如学校/院系最新规定与本规则冲突，以更新、更权威的本校文件为准。

请在使用时自行从学校研究生院的正式渠道取得对应版本，或向 Agent 上传校方文件，要求逐页核验。对无法确证的字号/缩进/表格复杂效果，Agent 应保留原稿并写入格式修正报告。
